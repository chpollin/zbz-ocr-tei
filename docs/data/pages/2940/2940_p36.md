# JEANNE HERSCH

(zu Marchal): Der Mensch ist ein kulturelles Wesen, das eine gemeinsame Geschichte braucht. Auch für die Genfer und Waadtländer ist Morgarten Realität geworden. Natürlich ist Tell eine Legende, aber historisch gesehen hat sie in der Schweiz faktische Folgen gehabt. Mythen haben auch geschichtliche Wirkungen.

(zu Gasteyger): Will man das Gewicht der Neutralität reduzieren, so muss man doch das Wichtige daran bewahren. Die Neutralität geht weit über das juristisch Fassbare hinaus, sie ist Bestandteil der schweizerischen Einstellung und Selbstauffassung. Ein Vereinigtes Europa hätte ein neutrales Mitglied vielleicht sogar nötig.

Man redet viel davon, was Europa der Schweiz geben kann. Umgekehrt: Was kann die Schweiz Europa geben? Ohne falschen Stolz dürfen wir eigene Züge vorweisen, die für Europa vielleicht günstig sein könnten.

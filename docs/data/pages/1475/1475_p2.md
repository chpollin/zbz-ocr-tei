# Vom guten und vom schlechten Tourismus

An jeder beliebigen Art von Tourismus sind wenigstens drei Teile direkt interessiert: erstens die Touristen selber, zweitens die sie aufnehmende Bevölkerung und drittens die davon profitierenden Unternehmungen.

# Zu den Touristen

Die Touristen können aus einer ganzen Reihe von Gründen schlecht verreisen. Ihr Bedürfnis, ins Ausland zu fahren, kann sich sehr unbestimmt äussern. Im extremen Fall so, dass man möglichst weit von zuhause

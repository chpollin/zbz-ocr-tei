Pas tout à fait, cependant. Cette aurore n'est pas la première. Quelque part, dans le nouveau silence, quelque chose, quelqu'un, une foule sans nombre n'a pas fini de gémir.

C'est le passé. C'est passé. Cela n'est plus. Ils ne sont plus, ces jours, ces nuits, ces années, ces siècles, ces minutes, ces instants ; ces batailles, ces pleurs, ce sang, ces camps, ces prisons, ces bals ; ces fêtes, ces rêves ; ces vivants. Ils ne sont plus du tout.

Pourquoi, alors, des historiens qui regardent à la loupe les documents anciens, des archéologues penchés sur un débris de poterie ou sur une pierre taillée, pourquoi tant de travail sous le soleil ou la lampe pour approcher la vérité de ce qui fut ? Puisque ce qui fut n'est rien, ceux qui furent ne sont rien — pourquoi ne peut-on pas en dire n'importe quoi ? Est-ce que, dans le néant, il n'y a pas place pour n'importe quoi ?

Bien sûr, il y a quelque part, chez quelques-uns, un reste de mémoire. Mais ce n'est pas de mémoire avant tout qu'il s'agit.

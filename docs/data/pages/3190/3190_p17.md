Hersch It is a good question, so let me try to answer it. I think "unmasking" facts, going behind the phenomena, is an important activity within legitimate limits. For instance, you can say that a given set of ethical concepts is linked with the structure of society, but you are never justified in saying that these values are the mere products of social structures. You have never the right to say that values are a curtain hiding the social facts from us. I don't think science can invalidate values. You cannot destroy them by "unmasking" them.

Note on status

This website is an experimental inspection environment of the running OCR/TEI pipeline and not a public edition frontend. Contents, metrics, and workflow status can change at short notice. The delivered edition is provided by ZBZ through its own systems.

The site was built with the Promptotyping method, an iterative software development practice with language models, documented in the repository.

Data and sources

Facsimile scans, reference TEIs, and editorial guidelines originate from the Zentralbibliothek Zurich and are subject to ZBZ's terms. Pipeline output (OCR, layout, derived TEI) is produced by the contractor and handed over to ZBZ at project completion.

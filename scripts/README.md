# scripts/

Python pipeline of the Jeanne Hersch edition, grouped by domain into subpackages.
All scripts are generated by Claude Code. Invoke as a module:
`python -m scripts.<package>.<module>`. Shared configuration (`config.py`) and
utilities (`utils.py`) live top-level.

The CLI reference with flags and examples is [../CLAUDE.md](../CLAUDE.md) §Commands.
Pipeline stages and data flow are in [../knowledge/pipeline.md](../knowledge/pipeline.md).

## Structure

| Package | Purpose | Key modules |
|---|---|---|
| *(top-level)* | shared base | `config.py` (paths, models, constants), `utils.py` |
| `core/` | domain-free shared library | `loaders.py` (OCR/layout discovery), `gemini.py` (client), `pb_split.py` (`<pb>` segmentation + per-page split of an assembled TEI, E69), `tei_xml_utils.py` |
| `ocr/` | text layer | `ocr_pipeline` (`-e auto` resolves to Gemini vision OCR, `-e mistral` keeps the delivered corpus reproducible), `gemini_ocr_correct`, `llm_postprocess` (Haiku, optional E17), `classify_docs` (Gemini metadata) |
| `layout/` | layout + export | `run_layout_analysis` (Docling local), `run_layout_cloud` (docling-serve), `layout_qa_gemini` (QA/detect/auto), `overlay` (bbox drawing + coordinate conversion), `generate_layout_overlays`, `page_xml_generator` + `mets_generator` |
| `tei/` | TEI generation | `tei_unified` (orchestrator), `tei_step1/2/3` (scaffold/Gemini/assembly), `tei_generator`, `tei_mapping_prompt`, `tei_validator`, `zbz_conformity` (inline-GND conformity rules the schema cannot express, E88), `tei_blank_marker`, `tei_status_marker` (E66), `tei_footnote_demote` (E85) + `tei_footnote_marker_strip` (redundant footnote-marker strip), `tei_surface_graphic` (E89), `tei_char_normalize` + `tei_pb_folio` + `tei_body_note_demote` (stock corrections, E94), `marker_common` (shared dry-run/backup scaffolding for the marker runs), `tei_reading_order_fix` (W19 worklist instrument, dry-run default; corpus reorder refuted, E99), `tei_cover_strip` (E-Periodica cover sheets, operator-gated) |
| `eval/` | quality | `evaluate_ocr` (CER/WER engine), `eval_report` (HTML), `benchmark_cer`, `cer_statistics` + `_runner` + `_full` (BCa/paired/HCPR), `quality_proxy`, `completeness_check`, `corpus_audit`, `structure_audit` (E84), `reading_order_audit` (W19 triage, E90), `char_lint_audit` + `pb_number_audit` + `hi_preservation_audit` + `relation_integrity_audit` + `body_note_audit` (guideline-conformity audits, E92), `blank_text_audit` (hallucinated text on blank pages), `audit_common` (shared TEI discovery + report scaffolding for the audits), `stability_pilot` (run-to-run CER spread, E100) |
| `edition/` | frontend data + export | `generate_edition_data` (catalog + mirror), `page_manifest` (per-object manifest), `extract_pages` (PDF -> PNG), `transkribus_export` (PAGE-XML upload bundle) + `transkribus_upload` (REST upload into a collection) |
| `entity/` | closed-world entity layer | `entity_lexicon` + `entity_matcher` + `running_heads` (lexicon construction, candidate search, running-head detection core; E105/E108), `tei_entity_preview` (preview runner), `fetch_gnd_variants` (lobid GND cache), `entity_lint`, `entity_corpus_scan`, `entity_gold_benchmark`, `entity_eval_sample`, `build_mention_verdicts`, `entity_verdict_guard` (adjudicated verdicts vs current scan, gate-capable, E110), `entity_risk_ranking`, `entity_corpus_digest`, `entity_unlisted_scan`, `running_head_audit` (detector validation + convention precision), `generate_entity_preview_data` (viewer entity mirror) + `generate_entity_overview` (per-document entity overview for docs/entities.html) |

## Common entry points

```bash
python -m scripts.ocr.ocr_pipeline -i data/source/pdf/{ID}.pdf -e mistral   # OCR
python -m scripts.layout.run_layout_analysis --doc {ID}                # layout
python -m scripts.tei.tei_unified --doc {ID}                           # TEI (3 stages: scaffold/Gemini/assembly)
python -m scripts.tei.tei_validator --all --html-report                # validation
python -m scripts.eval.corpus_audit                                    # corpus audit
python -m scripts.edition.generate_edition_data                        # viewer data
python -m scripts.edition.transkribus_export --sample                  # build Transkribus upload bundle
python -m scripts.edition.transkribus_upload --dry-run --collection {ID}  # upload (login via env vars)
```

## Tests

```bash
python -m pytest tests/ -q
```

Gates per domain:

- `test_cer_statistics.py`: statistics primitives (BCa/paired/HCPR)
- `test_corpus_audit.py`: corpus invariants + completeness gate
- `test_cer_extraction.py`: OCR/CER text extraction
- `test_tei_schema.py`: `tei_final` against `zbz_hersch.rng` (E68)
- `test_tei_header.py`: teiHeader delivery contract (idno + biblStruct + langUsage, E69)
- `test_tei_validator.py`: reference CER in percent (O24/E69)
- `test_pb_split.py`: `<pb>` segmentation byte-identical (E69)
- `test_reading_order.py` / `test_reading_order_audit.py` / `test_reading_order_fix.py`: reading order (permutation, W19 triage, in-place instrument, E90/E99)
- `test_stability_pilot.py`: run-to-run pilot aggregation + statistics wiring (E100)
- `test_scripts_health.py`: syntax + internal imports of all `scripts/`
- `test_char_lint_audit.py` / `test_pb_number_audit.py` / `test_hi_preservation_audit.py` / `test_relation_integrity_audit.py` / `test_body_note_audit.py`: guideline-conformity audits (E92)
- `test_step1_filter.py`: step-1 pb@n detection, filter-echo drop, folio interpolation (E92)
- `test_status_marker.py`: idempotent revisionDesc projection (E66)
- `test_completeness_check.py`: page-count reconciliation (split double pages, covers)
- `test_char_normalize.py` / `test_pb_folio.py` / `test_body_note_demote.py` / `test_marker_common.py`: stock-correction tools plus the shared dry-run/backup scaffolding (E94)
- `test_tei_conformance.py` / `test_zbz_conformity.py`: conformance fixes (E84) and the ZBZ conformity rules Z1-Z8 (E88)
- `test_footnote_demote.py` / `test_footnote_marker_strip.py` / `test_tei_surface_graphic.py` / `test_blank_text_audit.py` / `test_facs_mapping.py`: TEI stock fixes and their diagnostics (E85, E89, E114)
- `test_curated_loaders.py` / `test_page_names.py` / `test_workflow_status.py`: curated-input discovery, page-name conventions, workflow status model
- entity layer (`test_entity_*.py`, `test_variant_review.py`, `test_mention_verdicts.py`, `test_fetch_gnd_variants.py`, `test_generate_entity_overview.py`, `test_generate_entity_preview_data.py`, `test_running_head_audit.py`, `test_cover_strip.py`): matcher, lint, previews, corpus scan, verdict store and guard, gold benchmark, risk ranking, digest, unlisted scan, sample draw, mirror and overview generators, running-head detector, cover-sheet strip. The full gate command is in [../CLAUDE.md](../CLAUDE.md), entity integration section; the test strategy is in [../knowledge/verification.md](../knowledge/verification.md), quality assurance section

## Conventions

- Invoke as a module (`python -m scripts.<package>.<module>`), absolute imports
  `from scripts.<package>.<module> import ...`.
- Generated data belongs in `output/` (gitignored), never in `scripts/`.
- Removed with E66: the agent screening (`tei_quality_pass`, `tei_screening_prep`,
  `screening_prompt`), replaced by human-set workflow status
  (`tei.tei_status_marker`); see [../knowledge/workflow.md](../knowledge/workflow.md).
